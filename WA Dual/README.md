# Dual WhatsApp for macOS (WA Dual)

Native macOS shell around [WhatsApp Web](https://web.whatsapp.com) for a **second account** alongside the official WhatsApp Mac app.

For full setup, usage, and limitations, see the **[root README](../README.md)**.

## Quick start

```bash
open "WA Dual.xcodeproj"
```

Xcode → scheme **WA Dual** → **My Mac** → Run (⌘R).

Scan the QR code with your second phone: WhatsApp → Settings → Linked devices.
